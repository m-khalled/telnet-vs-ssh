Telnet vs SSH

مقارنة بين Telnet و SSH وإعدادهم على Cisco

وجه المقارنة Telnet SSH
الاسم الكامل Teletype Network Secure Shell
Port TCP 23 TCP 22
Transport Protocol (TCP/UDP) TCP TCP
Encryption مفيش، كل حاجة plain text مشفر بالكامل (AES, ChaCha20)
Authentication Username/password بـ plain text بس Password, Public key, Certificates, MFA
Server Authentication مفيش، مفيش طريقة تتأكد بيها إنك بتكلم السيرفر الصح Host key verification (fingerprint)
Sniffing الـ credentials والـ commands بتظهر clear text في Wireshark الـ payload بيظهر encrypted بس
Key Exchange مفيش Diffie-Hellman / ECDH
Integrity مفيش MAC / AEAD (زي HMAC-SHA2) لاكتشاف أي تعديل في الداتا
Cisco Setup line vty + password + login + transport input telnet hostname + ip domain-name + crypto key generate rsa + local user + transport input ssh
MITM سهل جداً صعب، والـ host key بيكشف الهجوم لو اتغير

أوامر Telnet

Telnet on Cisco
Router> enable
Router# configure terminal
Router(config)# enable secret cisco
Router(config)# line vty 0 4
Router(config-line)# password cisco123
Router(config-line)# login
Router(config-line)# transport input telnet
Router(config-line)# end
Router# copy running-config startup-config

الـ IP ده مثال، حط الـ IP بتاع الـ interface في الراوتر.

Telnet from PC (Command Prompt)
C:\> telnet 192.168.1.1

أوامر SSH

لازم hostname و ip domain-name يتكتبوا قبل crypto key generate rsa، وإلا الـ key مش هيتعمل. لاحظ إن الـ prompt بيتغير لـ R1 بعد أمر hostname.

SSH on Cisco
Router> enable
Router# configure terminal
Router(config)# hostname R1
R1(config)# ip domain-name lab.local
R1(config)# crypto key generate rsa modulus 2048
R1(config)# username admin privilege 15 secret StrongPass
R1(config)# enable secret cisco
R1(config)# ip ssh version 2
R1(config)# line vty 0 4
R1(config-line)# login local
R1(config-line)# transport input ssh
R1(config-line)# end
R1# copy running-config startup-config

الـ IP ده مثال، حط الـ IP بتاع الـ interface في الراوتر. -l معناها الـ username.

SSH from PC (Command Prompt)
C:\> ssh -l admin 192.168.1.1
